**Functional Requirements**

| ID | Functional Requirement |
| :---- | :---- |
| FR-01 | The system must let a user sign in with Google using their university account. |
| FR-02 | The system must allow researchers to create, customize, and publish research forms. |
| FR-03 | The system must allow researchers to add different question types, including multiple choice, checkbox, short answer, paragraph, and rating scale. |
| FR-04 | The system must let respondents filter the list of research studies to show only the studies they qualify for. |
| FR-05 | The system must calculate response frequencies, percentages, and applicable statistical summaries for quantitative questions. |
| FR-06 | The system must allow users to access both researcher and respondent functions using a single account. |
| FR-07 | The system must prevent researchers from submitting responses to their own research studies. |
| FR-08 | The system must support anonymous response submission for research studies configured for anonymous participation. |
| FR-09 | The system should allow researchers to create and manage interview schedules for qualitative research. |
| FR-10 | The system must prevent duplicate submissions when a research study allows only one response per respondent. |
| FR-11 | The system could allow respondents to view their previous research participation history. |
| FR-12 | The system must display published research studies to respondents, including each study’s title, description, researcher, and respondent requirements. |
| FR-13 | The system must allow respondents to answer the questions in a published research study and submit their responses. |
