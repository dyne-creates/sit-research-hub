**Non-Functional Requirements**

| ID | Non-Functional Requirement |
| :---- | :---- |
| NFR-01 | The system must protect user credentials and sensitive information from unauthorized access. |
| NFR-02 | The system must enforce access controls so that users can access only the data and functions that their permissions and ownership allow. |
| NFR-03 | The system must maintain the confidentiality of anonymous respondents and prevent their identities from being directly associated with their submitted answers. |
| NFR-04 | The system must maintain the accuracy and integrity of stored research responses and computed results. |
| NFR-05 | The system should provide regular data backups to minimize the risk of losing research records. |
| NFR-06 | The application must provide a user-friendly and understandable interface that allows students and researchers to navigate its features. |
| NFR-07 | The system should provide clear error messages and instructions when users enter invalid input or when operations fail. |
